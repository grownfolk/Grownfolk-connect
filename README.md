# Grownfolk Connect

This is the official connect page for Grown Folk United.  
It’s the front end of our mobile wallet onboarding system — built for QR access, profile verification, and one-click connection.

This is not a demo or template. This is live infrastructure.

---

## What This Repo Powers

- Connects wallets via WalletConnect (QR + browser)
- Links users to Join Now and profile creation on grownfolk.us
- Mobile-first experience for verified member access

---

## Tools Used

- **WalletConnect** — handles wallet pairing
- **GitHub** — version control
- **Pinta** — used for IPFS deployment (reliable routing)
- **Unstoppable Domains** — powers grownfolk.wallet
- **Ning** — powers the main platform at [grownfolk.us](https://grownfolk.us)

---

## Contract-Ready (Optional Backend)

This system runs without a smart contract, but it’s built for future integration:

- One-profile = one-vote smart contract voting  
- Non-transferable NFT membership  
- On-chain support statement tracking  
- Contributor dividend logic  

---

## Deployment Process

- Upload full folder to [https://pinta.cloud](https://pinta.cloud)  
- After deploying, use the new CID with your Unstoppable domain (e.g. yourname.wallet)
- Fleek was previously used but caused routing issues — Pinta resolved that
